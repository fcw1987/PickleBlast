# Security Policy

The current supported version is the 1.0 (4) development line on the main branch. Previous experimental builds are unsupported. There has been no App Store release.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/fcw1987/PickleBlast/security/advisories/new) for this repository. It is enabled and requires a GitHub account. Do not post vulnerabilities, exploit details, or sensitive information in a public issue. This private route is for security reports, not ordinary support questions.

Include the affected version or commit, potential impact, and a concise reproduction when practical. Remove credentials, signing files, personal information, device identifiers, and unrelated logs. GitHub processes private reports under its policies and shares them with authorized participants. The project does not promise a response time or operate a bug bounty.

## Scope

PickleBlast gameplay runs locally on Apple Watch and stores settings and records locally. It has no in-app account system, gameplay server, analytics, advertising, or runtime third-party service. The website and voluntary GitHub reports have separate processing described in [Privacy](PRIVACY.md). For ordinary help, use [Support](SUPPORT.md).
