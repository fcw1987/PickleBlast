# Security Policy

The current supported version is the 1.0 (4) development line on the main branch. Previous experimental builds are unsupported. There has been no public release.

## Reporting a vulnerability

If GitHub private vulnerability reporting is enabled for this repository, use that private reporting feature. Until it is available, send the report through private communication with the repository owner. Do not report a vulnerability in a public issue.

Include the affected version or commit, the potential impact, and a concise reproduction when practical. Remove credentials, signing files, personal information, device identifiers, and unrelated logs. The project does not promise a response time or operate a bug bounty.

## Scope

PickleBlast runs on Apple Watch and stores game settings and records locally. Its application code has no account system, gameplay server, analytics, advertising, or network integration. See [Privacy](PRIVACY.md).
