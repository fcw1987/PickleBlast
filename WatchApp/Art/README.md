# Approved runtime artwork

Generated by `python3 scripts/import_art.py` from the immutable `PickleBlast_Final_Approved_Art` handoff and the separately recorded original B3 environment sources. This folder includes the approved player and all five boss frame sets with one embedded paddle each, selected supporting atlases, and `runtime_manifest.json` for exact motion timing and registration. B3 replaces the former arena background and adds one unmarked blue court-material texture; both are opaque 512 × 512 images.

Do not hand-edit generated resources. See [art assets](../../docs/ART_ASSETS.md) for source mappings and rights status, and [build and test](../../docs/BUILD_AND_TEST.md) for the clean-checkout `--check-runtime` route and optional master regeneration. The tracked project already includes the selected `.atlas` folders and `runtime_manifest.json`; `import_audit.json` stays outside app resources. Master-resolution alternatives and unused bosses are not bundled.
